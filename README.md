- **핵심 내용**
  - 재고 초과, 중복 발급, 카운터-이력 일치, 상태 전이 유효성, 등급 미달 발급, 등급-주문 정합성 등 **6종 검증** 설계

  - 항목별 실행 시간을 측정한 결과 '등급-주문 정합성' 검증이 42.0초로 가장 느림 → 기존 인덱스를 활용하지 못하는 것이 원인
  - Flyway 마이그레이션으로 `orders(user_id, status, completed_at, paid_amount)` 복합 인덱스를 추가해 **42.0초 → 10.4초 (약 75% 단축)**
  - 검증 결과를 Notion 리포트로 연동해 이상 건수와 상세 내역을 바로 확인할 수 있게 구현
</details>
